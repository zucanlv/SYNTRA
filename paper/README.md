# SYNTRA paper

The paper and its Supplementary Information are available on arXiv:

**Self-improving data synthesis enables scalable adaptation of embedding models**  
Zucan Lyu, Rui Tang, Jianlyu Chen, Peisheng Jin and Defu Lian

- Abstract page: [arXiv:2610.14730](https://arxiv.org/abs/2610.14730)
- PDF (main text followed by Supplementary Information): <https://arxiv.org/pdf/2610.14730>

Earlier draft PDFs previously kept in this folder have been removed; please use the arXiv version.

[Accompanying files for Supplementary Note 1](../docs/supplementary/) include the shared prompt templates, task descriptors and selected instruction records, including the FiQA refinement case.
